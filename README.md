## BlackJack Rules
- 규칙이 뭐야 .. 블랙잭, 버스트,힛,스탠드,인슈어런스,스플릿..복잡한데 처음엔 걍 블랙잭, 버스트, 무승부push

- 카드 : 카드덱 52장 하트, 클로버, 스페이드, 숫자 2~10, JQK는 10점, A는.. 1 또는 11인데 이것도 복잡한데..

- 게임 순서:
- 딜러 2장, 플레이어 2장씩 받고 딜러 카드 1장 공개, 1장 비공개
- 플레이어가 딜러 카드 보고 Hit, Stand 결정
- 딜러 차례인데.. 17이상이면 안뽑고 17미만이면 무조건 뽑아야 되는데
- 이거 너무 복잡함 지금.. 처음부터 이런식이면 좀 그런데

- 그리고 이거.. 카드 1장을 보여주고 플레이어는 선택을 해야함
- 입력 받아야함 hit stand


## version 1
- 카드 랜덤 생성 (1~10)
- 플레이어 선택 Hit or Stand
- Hit 이면 한장 더 뽑고
- Stand면 게임 종료
- 여태까지 뽑은 카드를 전부 sum 해야함
- 그 값으로 승패 결정 
- 21 맞추면 승리 
- 맞출 확률 거의 없을것 같은데 일단 기본적으로 만들거는 만들어야함
